Base64 파일 전달 도구

구성
- android/: 파일 선택 → Gmail 작성 또는 클립보드 복사
- pc/: 받은 텍스트를 모아 원본 파일로 복원하는 Python 프로그램
- PROTOCOL.txt: 양쪽에서 공통으로 사용하는 데이터 형식

사용 흐름
1. 안드로이드 앱에서 1MiB(1,048,576바이트) 미만 파일을 선택합니다.
2. 작은 파일은 한 조각, 큰 파일은 원본 100KiB 단위로 나눕니다.
3. 현재 조각을 Gmail 본문으로 전달하거나 클립보드에 복사합니다.
4. 여러 조각이면 각 조각을 반복 전달합니다. 메일은 직접 전송합니다.
5. PC 프로그램에서 JSON 본문을 붙여 넣고 추가합니다.
6. 모든 조각이 모여 크기와 SHA-256 검증을 통과하면 저장합니다.

주의할 사용 특성
- 클립보드에 복사만 해서는 PC에 전송되지 않습니다.
- 다음 조각을 복사하면 이전 클립보드 내용은 대체됩니다.
- PC에서 조각을 추가하는 순서는 상관없습니다.
- Base64는 암호화가 아닙니다.
- 100KiB는 초기 구현의 조각 크기입니다. Android가 보장하는 최대값이
  아니며, 실제 휴대폰의 Gmail과 클립보드 동작을 확인해야 합니다.
- Windows는 Base64Restore.exe를 실행합니다. Python 별도 설치는 필요 없습니다.
- 소스(pc/launch.cmd) 실행은 Python 3와 Tk가 필요합니다.

자세한 실행/빌드 방법은 각 하위 폴더의 README.txt를 확인하세요.
