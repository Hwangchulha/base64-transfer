Text Transfer — PC 1.5.2 / Android 1.4

PC에서 파일 → 텍스트:
1. EXE 상단의 '파일 → 텍스트 만들기'를 누릅니다.
2. 1 MiB 미만 파일을 선택합니다.
3. '전체 텍스트 복사' 또는 '텍스트 파일 저장'을 누릅니다.
   복원 창에서는 '클립보드 붙여넣기'를 눌러 새 본문을 가져온 뒤 '텍스트 확인'을 누르세요.
4. 본문은 PC 복원 프로그램 1.4 이상에서 읽을 수 있습니다.
화면에는 앞부분만 미리보기하며 복사/저장에는 전체 본문이 포함됩니다.
Android 앱의 텍스트 → 파일 복원 기능은 아직 없습니다.

Text Transfer 1.4 — 먼저 무손실 압축

APK와 PC EXE를 모두 업데이트하세요. 새 본문은 이전 PC 버전에서 읽을 수 없습니다.

1. Android에서 파일을 선택합니다.
2. 텍스트 복사 또는 Gmail로 작성을 누릅니다.
3. 큰 본문은 Gmail 본문을 길게 눌러 붙여넣기를 한 번 합니다.
4. PC에서 메일 본문의 { } 전체를 복사합니다.
5. Base64Restore.exe에서 붙여넣기 → 텍스트 확인 → 원본 파일 저장.

본문에 한자·한글처럼 보이는 문자열이 나타나는 것은 정상입니다.
파일을 먼저 압축하고 전체 본문이 더 짧아질 때만 적용합니다.
앱에서 원본 → 압축 크기와 절감률을 확인하세요.
사진·ZIP·XLSX 등 이미 압축된 파일은 거의 줄지 않을 수 있습니다.
원본이 변하지 않으며 크기와 SHA-256을 확인한 뒤 복원합니다.
암호화는 아니며, 문자열을 가진 사람은 원본을 복원할 수 있습니다.

큰 텍스트용 주소(URI)는 더 이상 클립보드에 넣지 않습니다.
실제 일반 텍스트를 넣고 다시 읽어 확인한 뒤 성공을 표시합니다.
앱 자체 전달 기준은 Parcel 800KiB입니다. 따라서 1MiB 미만 파일이라도
복사 한도를 넘을 수 있습니다. 기준을 넘으면 분할 없이 이유를 알립니다.
기기별 공유 버퍼·키보드 정책에 따라 실패할 수 있으며, 실제 휴대폰의
키보드 기록/Gmail 동작은 아직 확인하지 못했습니다.

Windows EXE는 Python 별도 설치가 필요 없습니다.
전체 본문은 보관하되 미리보기는 앞부분256자만 표시합니다.
기존 v1/v2/v3 본문도 PC 프로그램에서 계속 복원할 수 있습니다.
