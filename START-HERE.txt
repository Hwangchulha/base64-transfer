Base64 Transfer 1.2 — 한 번에 복원

1. Android에서 1MiB 미만 파일을 선택합니다. 파일을 나누지 않습니다.
2. Gmail로 작성 또는 텍스트 복사를 선택합니다.
3. 작은 본문은 Gmail에 자동 입력됩니다. 큰 본문은 복사 후 Gmail이 열리며,
   본문을 길게 눌러 붙여넣기를 한 번 해야 합니다. 각 안내 메시지를 확인하세요.
4. PC에서 메일 본문의 JSON 전체를 복사합니다.
5. Base64Restore.exe에서 붙여넣기 → 텍스트 확인 → 원본 파일 저장.

큰 본문의 스트림 클립보드 붙여넣기는 받는 앱의 지원이 필요합니다.
실제 휴대폰 Gmail에서의 동작은 아직 검증하지 못했습니다.
붙여넣기가 안 되면 추가 분할이나 첨부 전송을 자동으로 하지 않습니다.

Windows EXE에는 Python이 포함됩니다. 별도 설치 없이 실행합니다.
소스 실행은 Python 3.9 이상과 Tk가 필요합니다.
이전 분할 버전의 텍스트도 PC 프로그램에서 계속 복원할 수 있습니다.
Base64는 암호화가 아니며, 클립보드는 PC와 자동 동기화되지 않습니다.
